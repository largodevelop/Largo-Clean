# Largo Clean

Анализ диска, очистка временных файлов и поиск давно не используемых приложений. Electron, семейство Largo.

## Запуск

```
npm install
npm start
```

Для очистки системных папок (`C:\Windows\Temp`, кэш Центра обновления) и отключения гибернации нужны права администратора: в приложении есть кнопка перезапуска.

## Сборка

```
npm run build
```

Готовая папка: `release/win-unpacked/Largo Clean.exe`.

## Как устроено

- `electron/scanner.cs` — обход диска через Win32 `FindFirstFileExW` (файлы не открываются), компилируется на лету через PowerShell `Add-Type`. Там же замер и удаление для очистки.
- `electron/cleaner.js` — список целей очистки. Удаляется только содержимое известных папок кэша и временных файлов; файлы младше суток и занятые пропускаются.
- `electron/apps.js` — установленные программы (реестр Uninstall) и игры Steam (appmanifest). Последний запуск: Steam `LastPlayed`, журнал Windows BAM, UserAssist, Prefetch и время доступа к exe с фильтром массовых касаний (антивирус, индексатор).
- `public/` — интерфейс.

Отладка: `LARGO_SHOT=<папка>` делает скриншоты всех разделов и закрывает приложение.
